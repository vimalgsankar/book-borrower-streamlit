# Library Management System

A modern, web-based Library Management System built with Streamlit and SQLite. 

## Features
- **Student Dashboard**: Browse catalog, borrow books, manage holds, and view borrowing history.
- **Admin Dashboard**: Manage users, catalog books, approve donations, and track library analytics.
- **Modern UI**: Fully responsive, clean interface with animations and modern design elements.

## Running Locally

1. Install requirements (Streamlit and Pandas):
   ```bash
   pip install streamlit pandas
   ```
2. Run the app:
   ```bash
   streamlit run app.py
   ```
3. On first run, the database will be automatically initialized and populated with sample data.
